Focus mode

One keystroke and the app gets out of the way.

⌘ . takes the window full screen, collapses both sidebars, fades the header and command bar, and dims every paragraph but the one you're in. Esc gives it all back, exactly where it was.

Chrome fades, doesn't vanish
The header and command bar drop to zero opacity over 300ms. Move the pointer onto either one — or tab into it — and it comes straight back.
Both panels collapse
History on the left, outline and backlinks on the right — both animate shut. Your open document keeps the full width of the screen.
Only this paragraph is lit
The block holding the caret stays at full contrast; everything above and below eases down to 30%. Move the caret and the light follows it.
Typewriter scrolling
The caret is held at the middle of the screen as you type. Clicking or drag-selecting never re-centres, so the text won't jump under your pointer.

Inside the app

A closer look at the surfaces you'll actually use.

Four panels, one shortcut each. Nothing floats over your page unless you called it.

01 — Command bar

Type a colon. Run anything.

The status line doubles as a vim-style prompt. Press : and start typing — commands match on their name or their description, so :ex and word both find what you meant.

  • ⌘⇧E Export to Word, PDF, EPUB
  • ⌘. Toggle focus mode
  • ⌘⇧O Toggle table of contents
  • ⌘U Version history sidebar

A suggestion you accept, or don't.

03 — Version history

Undo that branches, not a straight line.

Every save is a node. Step back with ⌘⌥Z, write something different, and the old path stays right where you left it — a second branch rather than a version you destroyed. Open the graph with ⌘U and read any node before you jump.

Nothing is uploaded to make this work. The tree is a file next to your writing.

Optional AI

Off by default. Yours to switch on, with the model you pick.

Memoire is a text editor first. The assistant ships disabled — no model downloaded, no key required, nothing listening. Turn it on and you choose where it runs and which model answers.

On this device

Quantised GGUF models run locally on your own hardware. The first one you pick downloads once — around 1.5 GB for the default — then works forever with the network off. Nothing you write is transmitted, because there is nowhere for it to go.

Works on a plane, in a cabin, behind a firewall

No API key, no account, no per-token bill

Swap models any time without losing a draft

Or a hosted model

Prefer something larger than your laptop can hold? Point Memoire at OpenRouter with your own key and pick any model it offers. The key is stored on your machine, and the choice is a dropdown — not a migration.

Your key, your account, your usage limits

Switch back to local in one click

Workflow

Open. Write. Ship. Three keys, start to finish.

  1. 01

    Capture without ceremony

    ⌘N opens a blank page in under 40 ms. No project wizard, no template picker, no folder to name before you've had the idea.

  2. 02

    Stay in the flow state

    Focus mode dims everything but the current paragraph. Session goals track words written today — never total, never a streak you're afraid to break.

  3. 03

    Export anywhere

    One command produces EPUB, DOCX with your editor's styles intact, clean PDF, or Markdown your static site already understands.

Shipped

Version control, with real Git sync

The branching history stays local. Git sync is the other half: point Memoire at a GitHub repository and every save becomes a commit you own, in a repo you can clone, diff, and read without us.

Sign in with GitHub, give it an owner/repo, and push with :push — or let it commit everything automatically when you close the app. Already have drafts on GitHub? Import pulls them down into your writing folder.

  • Plain Markdown commits — no proprietary sync format
  • Auto-push on exit, or manual, or never
  • Private repos; your token never leaves the machine
  • Works alongside the local version graph, not instead of it

First launch on macOS

Memoire isn't signed with an Apple Developer certificate yet, so macOS quarantines the download and says the app is damaged. It isn't — that's Gatekeeper refusing anything it can't trace to a paid certificate. Drag it to Applications, then strip the quarantine flag:

xattr -dr com.apple.quarantine /Applications/memoire.app

Run it once, in Terminal. It removes the com.apple.quarantine attribute from that one app and changes nothing else on your system. Right-click → Open works on Intel Macs too, but not on Apple Silicon.

Sorry about this step — I've been trying to get an Apple Developer account approved and haven't got anywhere yet. The moment it comes through, these builds get signed and notarized and the command goes away.

Open source

The source is public. Come break something.

Memoire is MIT-licensed and built in the open — a SvelteKit front end over a Rust core in Tauri. Issues, pull requests, and blunt opinions about the typography are all welcome.

Browse the code Open an issue

Report what broke

The most useful contribution is a bug report with the file that caused it — an export that mangled your formatting, a shortcut that fought your keyboard layout, a crash on open.

Pick up an issue

bun install, then bun run tauri dev, and you're running it locally. Svelte 5 and Tailwind on top, Rust underneath.

Argue about the craft

Line length, caret behaviour, what belongs in the command palette. Opinions from people who actually draft in it carry the most weight.
