What's new

A new Memoire, built around the page.

This release rebuilds every screen. Notes sit in the margin, history branches, the codex and library are redesigned, and long books stay fast. Tools float above the page and step aside when you are done.

See what you changed todayNew

Revise mode compares the page with how it was this morning. New words are underlined, cut words are struck through, right where they happened.

  • Step through each change from the bar above the page
  • Keep a change, or put the old words back
  • Compare with any earlier version, not only today
⌘⇧R

Notes in the marginNew

Select a line and leave yourself a note. It sits beside that line on wide screens, and in the scene panel on small ones.

  • Notes are saved inside the writing's file and never reach an export
  • The scene panel holds status, synopsis, notes, and who appears in the scene
  • See which writings link to this one
⌘⌥M note   ⌘⇧O panel

History that branches

Every save is a version. Go back to any of them, write something different, and the old path is still there.

  • Each version shows when it was saved and how it began
  • Step back and forward with the keyboard
  • Back up to GitHub or Dropbox when you choose
⌘U

A codex for your castRedesigned

Keep a sheet for every character, place, faction and object. Memoire finds them in your writing as you go.

  • Mentions per writing, chapter by chapter
  • See which characters keep turning up together
  • The assistant reads the sheets a scene mentions

Your library, as a list or as pagesNew

Binders hold a book, a collection or a journal, each with its own colour. Switch to cards to see how every writing opens.

  • Grouped by Today, Yesterday and earlier
  • Parts and chapters nest inside a binder
  • Recently deleted keeps anything you throw away

Everything from one box

Press ⌘K and type. Open a writing, find a codex entry, or run any command, each with its shortcut beside it.

  • Search across the whole project with ⌘⇧F
  • Find and replace with match case, whole word and regex
  • Focus mode hides everything but the page
⌘K

Sync

Optional sync, to storage you already own.

Your book is saved on your computer first. Turn on sync if you want a backup, or want to pick up the same book on another computer. It goes to your own GitHub repository or Dropbox folder, never to a Memoire server.

GitHubYour own repository, with a commit for every push
DropboxA folder you choose. Changed in both places? Both copies are kept

Off by default. Turn it on in Settings, and push when you quit if you like.

Privacy

Your book stays yours.

No account, no analytics, no copy on our servers. If Memoire disappeared tomorrow, your manuscript would still open.

Help build Memoire

It's open source under the MIT licence: a SvelteKit front end over a Rust core, packaged with Tauri. Issues and pull requests are welcome, and the most useful report is often a bug with the file that caused it.

bun install && bun run tauri dev
